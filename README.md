# DDOS_Attack_Lab



🚫 Lab 4.10: Denial-of-Service (DoS) Attacks (Zybooks)
This lab explores different types of Denial-of-Service (DoS) attacks, including protocol-based, network-based, and application-layer attacks. It demonstrates how these attacks affect system resources and services using real tools and traffic analysis.

🧠 Learning Objectives

--Launch TCP SYN, ICMP, and UDP flood attacks

--Simulate application-layer attacks using Slowloris

--Analyze DoS traffic with Wireshark

--Monitor system performance impacts using Windows Task Manager

🖥️ Environment
VMs Used:

--ZyKali01 (Kali Linux)

--ZyWin01 (Windows Server 2022)

✅ Tasks Completed

1) Executed TCP SYN flood with hping3

2) Sent oversized ICMP packets using ping

3) Launched UDP flood attacks via hping3

4) Simulated bandwidth exhaustion with ICMP

5) Performed Slowloris attack to overload web server application layers
